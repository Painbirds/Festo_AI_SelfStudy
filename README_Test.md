# Festo AI Self-Study

Microsoft 365 Copilot과 GitHub Copilot을 활용해 업무 문제를 정의하고, 작은 업무용 웹 도구를 직접 만들고 검증하는 10주 자기주도 학습 과정입니다.

## 학습 목표

- Microsoft 365 Copilot으로 문서, 메일, 회의, 데이터 업무를 효율화한다.
- 재사용할 수 있는 업무 프롬프트와 Prompt Library를 만든다.
- GitHub Copilot과 Visual Studio Code로 요구사항을 코드와 UI로 구현한다.
- 상태, 조건, 필터 등 기본 로직을 적용하고 디버깅과 테스트를 수행한다.
- 완성한 미니 앱을 문서화하고 Demo Day에서 시연한다.

## 전체 흐름

`업무 문제 선정` → `프롬프트 설계` → `M365 활용` → `Vibe Coding 입문` → `UI와 사용자 흐름 설계` → `기능 구현` → `디버깅과 테스트` → `문서화` → `발표와 회고`

| 주차 | 주제 | 핵심 내용 |

| 02 | Copilot 프롬프트와 Prompt Library | 좋은 프롬프트를 설계하고 재사용 가능한 프롬프트를 축적한다. |

## 기대 산출물

- 업무 문제 정의서
- 업무용 프롬프트와 Prompt Library
- 요구사항 및 사용자 흐름 정리
- 동작하는 업무용 미니 앱
- 테스트 및 디버깅 기록
- 사용 방법과 구현 내용 문서
- Demo Day 발표 및 회고 자료

## 권장 학습 방법

1. 매주 문서를 읽고 이번 주에 해결할 업무 문제를 한 가지로 좁힌다.
2. Copilot에 요청한 내용과 결과를 기록하고, 필요한 부분은 직접 검증한다.
3. 작은 기능 단위로 구현한 뒤 즉시 실행하고 테스트한다.
4. 마지막에는 앱, 문서, 발표 자료를 하나의 결과물로 정리한다.
